# 耳学習

個人の学習用に自動生成している音声メモの置き場です。通勤や家事の時間に聴くために、
自分用のノートから機械的に音声を作っています。

## お断り

- ここに置かれた音声は **すべて個人の学習目的で作成したもの** です。
- 内容には答弁の練習用に自分で書いた想定問答が含まれますが、
  **いかなる組織の公式見解でも、公式発表でもありません。**
- 元にしているのは、厚生労働省の通知や自治体の公表資料、報道など、
  いずれも一般に公開されている情報です。
- 音声は生成AIによる読み上げで、**実在の人物の声ではありません。**
  また自動生成のため、誤りが含まれることがあります。
